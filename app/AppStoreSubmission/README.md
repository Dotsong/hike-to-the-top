# App Store submission folder: Trail to the Top

Everything App Store Connect asks for, ready to drag in or paste.

| Folder or file | What it is | Where it goes |
| --- | --- | --- |
| `icon/AppIcon-1024.png` | App icon, 1024 x 1024, RGB, no transparency | Xcode: Assets.xcassets -> AppIcon |
| `screenshots/iPhone-1320x2868/` | Ten screenshots, 6.9-inch | The main iPhone slot |
| `screenshots/iPhone-1290x2796/`, `iPhone-1206x2622/`, `iPhone-1179x2556/`, `iPhone-1284x2778/`, `iPhone-1242x2688/` | The same ten at every other iPhone size Apple may ask for | Whichever slot rejects the first set |
| `screenshots/iPad-2064x2752/` | Ten screenshots, 13-inch iPad | The iPad slot |
| `screenshots/iPad-2048x2732/` | The same ten, 12.9-inch iPad | If the iPad slot asks for it |
| `header-5244x2950.png` | 16:9 header image, no transparency | "Header and Search Results"; turn on "Use header asset in search results" |
| `text/` | One file per field, numbered in the order App Store Connect asks | Paste each into its field |

Screenshots are numbered 01 to 10 in upload order. The `*-preview-sheet.png` files are contact sheets for a quick look; do not upload them.

The smaller iPhone and iPad sets are resized from the 6.9-inch and 13-inch captures, not captured separately.
